# CodeReviewX Personal Edition v0.1.0

CodeReviewX Personal Edition is the first Apple Silicon macOS DMG release.

## What is included

- Electron desktop shell with bundled Java 17 runtime.
- Bundled arm64 PostgreSQL and pgvector runtime; Docker, Homebrew, Java, and PostgreSQL are not required on the user's Mac.
- OpenAI-compatible model configuration with OpenAI, DeepSeek, Qwen, Moonshot, 智谱, MiMo, and custom presets.
- GitHub personal PAT flow for reading pull requests and manually approved comment publishing.
- Progressive first-launch wizard with macOS Keychain credential storage.
- Durable Review events, PR head SHA metadata, Evidence inspection, local Preview, and restart recovery.
- Evidence Gate and stable comment marker to prevent unsafe or duplicate GitHub writes.

## Important behavior

Embedding and Rerank are optional external services in this release. Without them, the app runs in `DEGRADED` mode: basic Review and local Preview remain available, but GitHub comment publishing is blocked until valid Evidence is available.

## Platform

- macOS Apple Silicon arm64 only.
- DMG is currently unsigned and not notarized. Public distribution should be limited to users who understand this Gatekeeper limitation until Developer ID signing and notarization are completed.
